   GND           GND             Common ground

         No external resistors needed. GPIO 33 provides more stable readings.

------------------------------------------------------------------------------
   MQ-7 Pin      ESP32 Pin       Notes
   ---------     ---------       -----
   VCC           5V (VIN)        Requires 5V for heater
   GND           GND             Common ground
   AO            GPIO 34         Analog output (0-4095 on ESP32)
   DO            Not connected   Digital output not used

   Note: MQ-7 requires 60-90 second warmup time for accurate readings.
         The blue PCB module has built-in circuitry.

------------------------------------------------------------------------------
3. MQ-135 AIR QUALITY SENSOR (Blue PCB Module)
------------------------------------------------------------------------------
   MQ-135 Pin    ESP32 Pin       Notes
   ---------     ---------       -----
   VCC           5V (VIN)        Requires 5V for heater
   GND           GND             Common ground
   AO            GPIO 32         Analog output (0-4095 on ESP32)
   DO            Not connected   Digital output not used

   Note: Detects NH3, NOx, alcohol, benzene, smoke, CO2.

4. HDC1080 TEMPERATURE & HUMIDITY SENSOR (I2C)
------------------------------------------------------------------------------
   HDC1080 Pin   ESP32 Pin       Notes
   -----------   ---------       -----
   VCC           3.3V            Use 3.3V (NOT 5V!)
   GND           GND             Common ground
   SDA           GPIO 21         I2C Data line
   SCL           GPIO 22         I2C Clock line

   I2C Address: 0x40 (default)
   Note: Can share I2C bus with LCD display.

5. 20x4 LCD DISPLAY (I2C Module with PCF8574 - 4 Pin)
------------------------------------------------------------------------------
   LCD Pin       ESP32 Pin       Notes
   -------       ---------       -----
   VCC           5V (VIN)        Requires 5V for backlight
   GND           GND             Common ground
   SDA           GPIO 21         I2C Data (shared with HDC1080)
   SCL           GPIO 22         I2C Clock (shared with HDC1080)

   I2C Address: 0x27 (common) or 0x3F (check your module)
   Display Size: 20 columns x 4 rows
   
   Note: The 4-pin I2C backpack (PCF8574) simplifies wiring.
         Adjust contrast using the blue potentiometer on the back.
         If display shows blocks, adjust contrast or check I2C address.

8. DUAL 18650 BATTERY SHIELD V8 (Power Supply)
------------------------------------------------------------------------------
   Shield Pin    ESP32 Pin       Notes
   ----------    ---------       -----
   5V OUT        VIN             Main power input to ESP32
   3.3V OUT      3.3V (optional) Can supplement ESP32's 3.3V regulator
   GND           GND             Common ground
   
   Battery Shield Features:
   • Input: 2x 18650 batteries (3.7V each, 7.4V total)
   • Output: 5V/3A and 3.3V/1A regulated
   • Built-in charging circuit (1A charge rate)
   • Over-discharge protection (cuts off at ~3.0V per cell)
   • Over-charge protection (stops at 4.2V per cell)
   • USB charging port (Micro-USB)
   • Power indicator LEDs
   • ON/OFF switch
   
   Battery Recommendations:
   • Use high-quality 18650 cells (Samsung, Panasonic, LG)
   • Capacity: 2500mAh or higher for longer runtime
   • Protected cells preferred for additional safety
   • Match battery capacities (don't mix old/new batteries)
   
   Charging:
   • Connect Micro-USB cable to shield's charging port
   • Red LED: Charging in progress
   • Green LED: Charging complete
   • Charge time: ~4-6 hours for 2500mAh batteries
   
   Runtime Estimation:
   • 2x 2500mAh batteries = 5000mAh total at 3.7V
   • System draws ~800mA at 5V
   • Estimated runtime: 4-6 hours continuous operation
   
   Safety Notes:
   • Never short-circuit battery terminals
   • Remove batteries if not used for extended periods
   • Don't expose to extreme temperatures
   • Use proper 18650 batteries (not cheap/fake ones)

================================================================================
                         I2C BUS CONFIGURATION
================================================================================

The I2C bus (GPIO 21 SDA, GPIO 22 SCL) is shared between:
  • HDC1080 (Address: 0x40)
  • LCD 20x4 (Address: 0x27 or 0x3F)

Both devices can coexist on the same I2C bus since they have different addresses.

To scan for I2C devices, use this code snippet:
```cpp
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA, SCL
  
  Serial.println("Scanning I2C bus...");
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Device found at 0x%02X\n", addr);
    }
  }
}
```

================================================================================
                         ADC NOTES (IMPORTANT!)
================================================================================

ESP32 has two ADC units:
  • ADC1 (GPIO 32-39): Works normally, even with WiFi active
  • ADC2 (GPIO 0, 2, 4, 12-15, 25-27): DOES NOT WORK when WiFi is enabled!

This project uses ADC1 pins only:
  • GPIO 34 (ADC1_CH6) - MQ-7
  • GPIO 33 (ADC1_CH5) - MQ-2
  • GPIO 32 (ADC1_CH4) - MQ-135

DO NOT use ADC2 pins for sensors if WiFi is required!

================================================================================
                         WIRE LENGTH RECOMMENDATIONS
================================================================================

For ceiling-mounted sensor unit to wall-mounted control panel:

  Recommended wire length: 4-5 meters maximum

  Wire gauge recommendations:
  • Power (5V, GND): 22 AWG or thicker
  • I2C (SDA, SCL): 22-24 AWG, keep as short as possible
  • Analog signals: 22-24 AWG, shielded if possible

  Tips for long wire runs:
  • Use twisted pairs for I2C lines
  • Add 4.7K pull-up resistors on SDA and SCL if I2C becomes unreliable
  • Keep analog sensor wires away from power lines to reduce noise

================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: Sensors show 0 or 4095 constantly
  → Check VCC and GND connections
  → Verify using ADC1 pins (not ADC2)
  → Allow 2-3 minutes warmup time for MQ sensors

Problem: LCD not displaying
  → Check I2C address (try 0x27 and 0x3F)
  → Adjust contrast potentiometer on LCD backpack
  → Verify SDA/SCL connections

Problem: HDC1080 not responding
  → Ensure using 3.3V (not 5V!)
  → Check I2C address 0x40
  → Run I2C scanner to verify detection

Problem: Buzzer not sounding
  → Verify GPIO 25 connection
  → Check buzzer polarity (+ to GPIO, - to GND)
  → Test with simple digitalWrite(25, HIGH)

Problem: WiFi disconnects frequently
  → Ensure using 2.4GHz network (ESP32 doesn't support 5GHz)
  → Check signal strength
  → Verify SSID and password in config.h

Problem: Battery shield shuts down immediately when all loads connected
  → Battery voltage reads full on multimeter but system won't power on
  → Likely causes:
     1. UNLABELED BATTERIES: Unknown capacity/condition, high internal resistance
        - Even if charged, can't supply 800mA current draw
        - Voltage collapses under load, triggering protection circuit
        - Solution: Replace with quality 2500mAh+ labeled batteries
     
     2. COUNTERFEIT/DEGRADED BATTERIES: Fake or old 18650s
        - Show 3.7V when idle but fail under load
        - Internal resistance too high
        - Solution: Use only genuine batteries (Samsung, Panasonic, LG)
     
     3. INSUFFICIENT BATTERY CAPACITY: Using 1200mAh or similar low-capacity cells
        - Total capacity too low for 800mA system draw
        - Estimated runtime: only 1.5 hours
        - Solution: Use 2500mAh+ batteries for 4-6 hour runtime
  
  → Diagnostic steps:
     1. Test with ESP32 only (no sensors) - should stay on
     2. Add sensors one by one to identify which causes shutdown
     3. If ESP32 alone works but adding sensors fails = battery capacity issue
     4. If ESP32 alone fails = battery is defective or counterfeit

Problem: Battery shows full charge but won't power system
  → Multimeter shows 3.7V but system shuts down under load
  → This indicates HIGH INTERNAL RESISTANCE (battery is degraded)
  → Solution: Replace battery immediately - it's unsafe and unreliable
  → Always use labeled, quality 18650 batteries from reputable sources
