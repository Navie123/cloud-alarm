2. MQ-7 CARBON MONOXIDE SENSOR (Blue PCB Module)
------------------------------------------------------------------------------
   MQ-7 Pin      ESP32 Pin       Notes
   ---------     ---------       -----
   VCC           5V (VIN)        Requires 5V for heater
   GND           GND             Common ground
   AO            GPIO 34         Analog output (0-4095 on ESP32)
   DO            Not connected   Digital output not used

   Note: MQ-7 requires 60-90 second warmup time for accurate readings.
         The blue PCB module has built-in circuitry.

------------------------------------------------------------------------------
3. MQ-135 AIR QUALITY SENSOR (Blue PCB Module)
------------------------------------------------------------------------------
   MQ-135 Pin    ESP32 Pin       Notes
   ---------     ---------       -----
   VCC           5V (VIN)        Requires 5V for heater
   GND           GND             Common ground
   AO            GPIO 32         Analog output (0-4095 on ESP32)
   DO            Not connected   Digital output not used

   Note: Detects NH3, NOx, alcohol, benzene, smoke, CO2.
         Best for detecting combustion byproducts.

------------------------------------------------------------------------------
4. HDC1080 TEMPERATURE & HUMIDITY SENSOR (I2C)
------------------------------------------------------------------------------
   HDC1080 Pin   ESP32 Pin       Notes
   -----------   ---------       -----
   VCC           3.3V            Use 3.3V (NOT 5V!)
   GND           GND             Common ground
   SDA           GPIO 21         I2C Data line
   SCL           GPIO 22         I2C Clock line

   I2C Address: 0x40 (default)
   Note: Can share I2C bus with LCD display.

------------------------------------------------------------------------------
5. 20x4 LCD DISPLAY (I2C Module with PCF8574)
------------------------------------------------------------------------------
   LCD Pin       ESP32 Pin       Notes
   -------       ---------       -----
   VCC           5V (VIN)        Requires 5V for backlight
   GND           GND             Common ground
   SDA           GPIO 21         I2C Data (shared with HDC1080)
   SCL           GPIO 22         I2C Clock (shared with HDC1080)

   I2C Address: 0x27 (common) or 0x3F (check your module)
   Note: Adjust contrast using the blue potentiometer on the back.

------------------------------------------------------------------------------
6. PIEZOELECTRIC BUZZER (Active Type)
------------------------------------------------------------------------------
   Buzzer Pin    ESP32 Pin       Notes
   ----------    ---------       -----
   (+) Positive  GPIO 25         Signal pin
   (-) Negative  GND             Common ground

   Note: Active buzzers produce sound when voltage is applied.
         No PWM frequency control needed.

================================================================================
                         I2C BUS CONFIGURATION
================================================================================

The I2C bus (GPIO 21 SDA, GPIO 22 SCL) is shared between:
  • HDC1080 (Address: 0x40)
  • LCD 20x4 (Address: 0x27 or 0x3F)

Both devices can coexist on the same I2C bus since they have different addresses.

To scan for I2C devices, use this code snippet:
```cpp
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA, SCL
  
  Serial.println("Scanning I2C bus...");
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {
      Serial.printf("Device found at 0x%02X\n", addr);
    }
  }
}
```

================================================================================
                         ADC NOTES (IMPORTANT!)
================================================================================

ESP32 has two ADC units:
  • ADC1 (GPIO 32-39): Works normally, even with WiFi active
  • ADC2 (GPIO 0, 2, 4, 12-15, 25-27): DOES NOT WORK when WiFi is enabled!

This project uses ADC1 pins only:
  • GPIO 34 (ADC1_CH6) - MQ-7
  • GPIO 33 (ADC1_CH5) - MQ-2
  • GPIO 32 (ADC1_CH4) - MQ-135

DO NOT use ADC2 pins for sensors if WiFi is required!

================================================================================
                         WIRE LENGTH RECOMMENDATIONS
================================================================================

For ceiling-mounted sensor unit to wall-mounted control panel:

  Recommended wire length: 4-5 meters maximum

  Wire gauge recommendations:
  • Power (5V, GND): 22 AWG or thicker
  • I2C (SDA, SCL): 22-24 AWG, keep as short as possible
  • Analog signals: 22-24 AWG, shielded if possible

  Tips for long wire runs:
  • Use twisted pairs for I2C lines
  • Add 4.7K pull-up resistors on SDA and SCL if I2C becomes unreliable
  • Keep analog sensor wires away from power lines to reduce noise

================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: Sensors show 0 or 4095 constantly
  → Check VCC and GND connections
  → Verify using ADC1 pins (not ADC2)
  → Allow 2-3 minutes warmup time for MQ sensors

Problem: LCD not displaying
  → Check I2C address (try 0x27 and 0x3F)
  → Adjust contrast potentiometer on LCD backpack
  → Verify SDA/SCL connections

Problem: HDC1080 not responding
  → Ensure using 3.3V (not 5V!)
  → Check I2C address 0x40
  → Run I2C scanner to verify detection

Problem: Buzzer not sounding
  → Verify GPIO 25 connection
  → Check buzzer polarity (+ to GPIO, - to GND)
  → Test with simple digitalWrite(25, HIGH)

Problem: WiFi disconnects frequently
  → Ensure using 2.4GHz network (ESP32 doesn't support 5GHz)
  → Check signal strength
  → Verify SSID and password in config.h
