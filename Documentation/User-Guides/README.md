# FireWire User Guides
## Simple Guides for Non-Technical Users

These guides are written in plain, simple language for Filipino residential households who are not technical experts.

---

## 📚 Available Guides

### 1. [Maintenance Guide](MAINTENANCE_GUIDE.md)
**What's inside:**
- Monthly tasks (cleaning, calibration, battery check)
- Every 3 months tasks (testing, inspection)
- Battery care and replacement
- Screen care
- WiFi connection updates
- Maintenance checklist

**Who needs this:** Everyone who owns FireWire
**How often:** Check monthly

---

### 2. [Safety Guide](SAFETY_GUIDE.md)
**What's inside:**
- What FireWire does and doesn't do
- Where to install (and where NOT to install)
- Installation safety
- Electrical safety
- Battery safety (very important!)
- Fire safety procedures
- Carbon monoxide safety
- Gas leak safety
- Child safety
- Emergency contact numbers

**Who needs this:** Everyone in the household
**How often:** Read once, review yearly

---

### 3. [Troubleshooting Guide](TROUBLESHOOTING_GUIDE.md)
**What's inside:**
- Screen problems (black screen, weird characters, brightness)
- WiFi connection problems
- Sensor problems (false alarms, not working)
- Battery problems (dies fast, won't charge)
- Website/app problems (can't open, can't log in, no notifications)
- Button problems
- Buzzer problems
- Quick reference table

**Who needs this:** Anyone having problems with FireWire
**How often:** When you have a problem

---

## 🎯 How to Use These Guides

### For New Users:
1. **Start with Safety Guide** - Read this first to stay safe
2. **Read Maintenance Guide** - Learn how to take care of FireWire
3. **Keep Troubleshooting Guide handy** - For when you need help

### For Experienced Users:
- Use Maintenance Guide monthly checklist
- Refer to Troubleshooting Guide when problems occur
- Review Safety Guide yearly

- Maintain it regularly
- Use it safely
- Know how to fix common problems

These guides help you do all three!
